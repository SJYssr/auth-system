# 应用授权管理系统

## 环境要求

- **JDK 17+**
- **Maven 3.6+**
- **Node.js 18+**
- **MySQL 8.0+**

## 项目结构

```
auth-system/
├── auth-system-boot/          # Spring Boot 后端
│   └── src/main/resources/
│       ├── schema.sql         # 数据库初始化脚本
│       └── application.yml    # 后端配置
├── src/                       # Vue 3 前端
├── package.json
└── vite.config.js
```

## 快速启动

### 1. 初始化数据库

在 MySQL 中执行 `schema.sql`：

```bash
mysql -u root -p < auth-system-boot/src/main/resources/schema.sql
```

### 2. 启动后端

```bash
cd auth-system-boot
mvn spring-boot:run
```

后端默认运行在 `http://localhost:8080`。

### 3. 启动前端

```bash
npm install
npm run dev
```

前端默认运行在 `http://127.0.0.1:3000`，开发模式下自动代理 `/api` 请求到后端。

## 对外接口

以下接口供客户端应用调用，所有接口均为 POST 请求。

### 客户端登录（卡密激活）

```
POST /login
```

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| Softid | string | 是 | 应用标识 |
| Card | string | 是 | 卡密号码 |
| Mac | string | 是 | 机器码 |
| Version | string | 是 | 客户端版本号（强制更新时校验） |

**成功响应：**

```json
{ "token": "a1B2c3D4e5F6g7H8" }
```

**失败响应：**

```json
{ "errcode": "-1001" }
```

| errcode | 说明 |
|---------|------|
| -1001 | 缺少必填参数 |
| -1002 | 机器码不匹配（非首次登录的设备） |
| -1004 | 卡密不存在或不属于该应用 |
| -1005 | 卡密已过期 |
| -1006 | 卡密已被禁用 |
| -1007 | 应用不存在或已下架 |
| -1008 | 版本过低需更新（应用开启强制更新且客户端版本号与最新版本不一致） |

**逻辑说明：**
- **强制更新检查**：若应用开启强制更新，则比对客户端 Version 与最新版本号，不一致则拒绝登录返回 -1008
- **首次登录**：写入机器码、激活时间、激活IP，扣除全部点数，到期时间 = 卡密类型 × 点数（如天卡×3点=3天，月卡×2点=2月），登录次数+1，返回16位Token
- **再次登录**：校验机器码是否一致、是否已过期，更新最近登录时间和IP，登录次数+1，返回新Token
